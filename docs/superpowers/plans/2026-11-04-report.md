# Report Implementation Plan

**Goal:** Generate cached, local activity trend HTML reports.  
**Architecture:** CLI delegates to report operation; Core reads all matching records; a bundled template renders escaped data and local SVG charts.  
**Tech Stack:** Python standard library, SQLite, HTML and SVG.  
**Spec:** docs/design/03-activity-report/report-system.md

1. Add behavioral tests for cache, forced refresh, account isolation and empty/malicious data; verify failure.
2. Enable unlimited internal reads while retaining existing public query limits.
3. Implement local template, statistical aggregation and secure atomic report writes.
4. Connect Action and CLI; run report tests and complete suite using synthetic data.
